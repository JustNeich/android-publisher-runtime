# Android Publisher

Готовая служба для macOS: получает MP4 из привязанного Telegram-топика, предлагает Да/Нет и после одобрения загружает через Android в YouTube Shorts по согласованному расписанию. Работает при закрытом чате Codex; Mac должен быть включён и не спать.

Установка **без плагина Codex**. Передайте Codex ссылку на этот репозиторий и поручите прочитать [AGENTS.md](AGENTS.md) и [docs/setup.md](docs/setup.md). Codex получает код, устанавливает зависимости и ведёт настройку. GitHub-аккаунт не нужен. Вы выбираете телефон, канал, Telegram-группу/топик, расписание и правила; подтверждаете входы и системные/USB-разрешения.

macOS Apple Silicon или Intel, Android 13+, общий Wi-Fi, работающий Internet/YouTube и вход Codex через ChatGPT. Первое подключение — Type-C. После перезагрузки телефона могут вновь потребоваться разблокирование и USB.

Версия движка **1.0.0-rc.3**, standalone-доставка. Это кандидат, **pending_live_acceptance**, не stable. [Проверки и границы](docs/verification.md) · [Восстановление](docs/operations.md).

Репозиторий содержит только отобранный код, инструкции, тесты и закреплённые wheels. Рабочие очереди, аккаунты, история исходного приватного репозитория и секреты не распространяются. Публичность исходника не предоставляет доступ к чьим-либо каналам.
